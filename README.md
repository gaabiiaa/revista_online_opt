
# Revista Online

O platformă web dinamică dezvoltată în PHP pentru gestionarea și publicarea conținutului editorial. Proiectul simulează o revistă digitală, permițând cititorilor să navigheze fluid prin articole, iar administratorilor să gestioneze publicațiile.

## 🚀 Funcționalități
* **Afișare dinamică a articolelor:** Conținutul este preluat și afișat dintr-o bază de date relațională.
* **Categorizare:** Structurarea articolelor pe secțiuni tematice pentru o navigare mai ușoară.
* **Panou de administrare (Admin Panel):** Funcționalități de tip CRUD (Create, Read, Update, Delete) pentru adăugarea, editarea și ștergerea articolelor.
* **Interfață prietenoasă:** Design curat și structurat pentru o experiență de lectură optimă.

## 🛠️ Tehnologii folosite
* **Backend:** PHP
* **Bază de date:** MySQL
* **Frontend:** HTML, CSS (și Bootstrap)
